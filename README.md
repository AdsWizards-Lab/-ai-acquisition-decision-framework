# Constrain or Expand?

### A decision framework for calibrating autonomy in AI-driven acquisition systems

Modern acquisition platforms increasingly control targeting, matching, bidding, creative selection, and distribution.

The operational question is no longer simply whether to automate.

It is:

> **When should an AI-driven acquisition system be constrained, and when should it be allowed to explore?**

This framework from **AdsWizards Lab** provides a structured way to make that decision.

## The four variables

The decision is evaluated across four variables:

### 1. Signal Confidence
How reliable is the optimization signal the system is learning from?

### 2. Cost of Error
What happens when the system explores in the wrong direction?

### 3. Value of Learning
How valuable is the information gained from allowing additional exploration?

### 4. Economic Headroom
How much inefficient exploration can the business afford while the system learns?

## Decision states

The interaction between these variables resolves into four operating modes:

- **Constrain**
- **Controlled Explore**
- **Expand in Stages**
- **Expand**

The goal is not maximum automation or maximum control.

The goal is to give the system enough freedom to learn **without allowing the cost of exploration to exceed the value of what can be learned.**
